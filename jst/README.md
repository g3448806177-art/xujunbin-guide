# jst（先理解再审批 + 按难度分配模型）

一个用口令开关的 Agent Skill：

- 说「使用jst」（或调用 `$jst`）开启，说「关闭jst」关闭；新对话默认关闭。
- 开启后，每个新任务先说明目标、步骤、交付和关键假设，**等你批准再动手**；批准前不做查询、文件处理或外部操作。
- 每次批准后，按子任务难度选择轻量 / 通用 / 高能力模型和推理档位分配给子体，只给最小必要上下文，减少不必要的 token 消耗。

## 安装

- **Codex**：把 `jst` 文件夹复制到 `~/.codex/skills/`。
- **Claude Code**：把 `jst` 文件夹复制到 `~/.claude/skills/`。

技能里举例的模型名称只是示例，实际以当前环境可用的模型为准；环境不支持子体或指定模型时，会照常完成任务并说明限制。
